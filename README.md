# Garnet Apple Battle

Telegram-бот для приватной 10‑вопросной таймованной викторины на ивентах; участники входят по одноразовому QR‑токену, результаты видны только администратору.

Spec: [`docs/blueprint.md`](docs/blueprint.md).

Built on [agnt-gm.ai](https://agnt-gm.ai). The whole bot is built and refined here as pull requests across successive build passes.
